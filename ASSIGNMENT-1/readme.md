# Smart Utility Toolkit

Lab Assignment 1 – Web Dev III

This project is a Node.js backend lab assignment that demonstrates the use of Node.js core modules such as `process`, `http`, `fs`, and `crypto`.

## Technologies Used

- Node.js
- JavaScript (ES6)
- Terminal / Command Prompt
- Node.js Core Modules
  - process
  - http
  - fs
  - crypto
